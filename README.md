# NAZWA_PROJEKTU

Krótki opis celu projektu.

## Start

1. Uzupełnij lokalnie `.env` na podstawie `.env.example`.
2. Przeczytaj kolejno: `README.md`, `STATUS.md`, `GIT-FLOW.md`, `AGENTS.md`, `HANDOFF.md`.
3. Wykonuj polecenia środowiskowe przez `dxrun`.

## Dokumentacja

- `AGENTS.md` — granice i zasady dla agentów AI
- `GIT-FLOW.md` — branch, testy, commit, push i PR
- `STATUS.md` — aktualny stan projektu
- `HANDOFF.md` — przekazanie do następnej sesji
- `CHANGELOG.md` — historia zmian
- `docs/` — dokumentacja specyficzna dla projektu

## Lokalne dane

Lokalne cache, raporty i pliki tymczasowe trafiają wyłącznie do `.local/`. Katalog jest ignorowany przez Git.
